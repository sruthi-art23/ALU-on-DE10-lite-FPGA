# ALU-on-DE10-lite-FPGA
DIGITAL CALCULATOR USING  INTEL  MAX10 FPGA -DE10 lite with verilog

🎯Overview :
    • Designed and implemented a Digital Calculator using Intel altera max 10 FPGA on the de10-lite board.
    • Developed using Verilog HDL and Intel Quartus prime. 
    • Performs basic arithmetic operations like Addition, Subraction, Multiplication and Division. 
    
🧠Design Approach:
      ↦Toggle switches SW0–SW7 used for data input
      ↦SW8–SW9 used for operation selection
      ↦Push buttons used for operand latching and mode selection
      ↦Designed seven-segment display drivers for real-time visualization

🛠Implementation Flow:
       ◈Verilog RTL design
       ◈RTL Viewer & Technology Map
       ◈Pin Planner & Chip Planner
       ◈Analysis & Synthesis
       ◈Fitter and Post-Map verification
       ◈Final hardware output validation on fpga

🔧Project Highlights:
      ►Supports Addition, Subtraction, Multiplication & Division
      ►8-bit input operands with 16-bit result handling
      ►Real-time result display using six seven-segment displays
   
🔎Tools used:
      ▴Intel Quartus Prime software
      ▴Intel Altera de10 max fpga
